## 6. 产品风险提示

- **04 链接下载（2026-11-19 按需求实现）**：仅对用户显式粘贴的 http(s) 媒体**直链**发起 GET，
  不解析第三方平台页面、不嗅探页面内媒体地址、不上传任何内容；响应必须是音频/视频类型，
  HTML 错误页一律拒绝入库。为此新增 `INTERNET` / `ACCESS_NETWORK_STATE` 两个权限与 OkHttp 依赖，
  其余页面仍为纯本地实现。来源合法性由使用者自行负责；上线前需单独做内容合规与隐私政策评审。
- **明文流量**：Android 9+ 默认禁用明文 HTTP，04 为支持用户粘贴的 http 直链设置了
  `android:usesCleartextTraffic="true"`。若上线要收紧，改用 `res/xml/network_security_config.xml`
  域名白名单即可，无需改代码。
- **转码前台服务**：本期导出与下载在页面生命周期内的协程中完成，未引入
  `FOREGROUND_SERVICE_MEDIA_PROCESSING`；P2 若接到后台转码，需处理 6h/天配额与主动 stop。
- **平台差异**：iOS 沙盒下「扫描本机文件」实际走文件 App / 文档选择器；
  Android 需 `READ_MEDIA_AUDIO`（API 33+）或 `READ_EXTERNAL_STORAGE`（≤32）。
- **专辑封面可用性**：MediaStore `albumart` URI 在部分 OEM / 无内嵌封面的文件上返回空，
  需统一兜底渐变封面。
